# Job Copilot v0.9.0

## 本次更新

- 岗位进度列表新增 `×` 按钮，可提前关闭不想继续检测或投递的岗位。
- 关闭后岗位立即移出投递列表，剩余岗位序号自动连续重排。
- 正在分析的岗位被关闭后，迟到的 AI 结果不会触发沟通，自动投递继续处理下一个岗位。
- 已关闭岗位在当前自动投递会话中保持排除，页面重新扫描或恢复任务时不会重新出现。
- 自动投递改为主按钮单次确认启动，并显示启动中状态，避免重复点击。
- “定位下一个达标岗位”只定位达到最低分的岗位。

## 安装与升级

1. 下载并解压 `Job-Copilot-BOSS-Assistant-v0.9.0.zip`。
2. 在 Edge 的 `edge://extensions/` 或 Chrome 的 `chrome://extensions/` 中打开开发者模式。
3. 首次安装请选择解压后直接包含 `manifest.json` 的目录；升级已有版本时，用新文件覆盖原目录后点击“重新加载”。
4. 刷新已经打开的 BOSS 职位页。

升级前建议先暂停自动投递。浏览器本地保存的配置通常会保留，重要简历和提示词仍建议自行备份。
