- Manifest V3 版本、JSON 格式与 JavaScript 语法检查。
- 52 个 Node 回归测试脚本全量通过。
- 职位列表导航保护、暂停/继续、批次切换、岗位关闭和失败恢复。
- OpenAI Chat/Responses、Anthropic、Gemini、Azure 与兼容接口边界。
- AI 空正文单次重试、`reasoning_content` 恢复、结构校验、本地 JSON 修复、截断保护与 token 统计。

- 沟通中岗位标记在点击前持久化，存储失败时停止点击，恢复、导航和关闭岗位时成对清理状态。

## 发布后首次真实环境冒烟

以下步骤会使用真实 BOSS 账号或产生真实沟通，只应由发布者对明确选择的测试岗位执行：

1. 重新加载 1.0.0，并刷新一个 BOSS 职位列表页。
2. 确认面板版本显示 1.0.0、列表可扫描、配置可读取。
3. 仅选择少量明确测试岗位，验证完整 JD、AI 评分、暂停与继续。
4. 对一个明确允许沟通的达标岗位验证原生“立即沟通”，确认职位标签不进入消息页或详情页。
5. 模拟一次可恢复的沟通失败，确认“重试沟通”不重新请求 AI，完成后主队列仍暂停。
6. 若出现登录、验证码、安全验证或页面遮罩，确认插件停止并等待人工处理。

如 BOSS 页面结构更新导致按钮无法精确命中，应保持失败并保留岗位，不应放宽 URL、坐标或遮挡校验。
