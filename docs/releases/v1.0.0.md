# Job Copilot v1.0.0

1.0.0 是 Job Copilot BOSS 助手的首个稳定版。

## 重点变化

- 自动“立即沟通”使用浏览器原生可信点击，执行前验证 BOSS 职位页、岗位 URL、页面地址、视口坐标和命中元素，执行后立即释放调试会话。
- Job Copilot 自身面板不再遮挡底层沟通按钮；BOSS 登录、安全验证和其他页面遮罩仍会阻止自动操作。
- 沟通失败的达标岗位可单独“重试沟通”，复用已有评分，不重复调用 AI，完成后保持主队列暂停。
- AI 空正文最多自动重试一次；兼容将结果放在 `reasoning_content` 的服务商，并能从带推理说明或元数据对象的正文中找到结构正确的分析结果。
- 目标方向直接匹配时稳定进入高相关区间；经验、应届、岗位级别或次要技能缺口不会跨维度重复扣分。
- 保留导航安全保护、多厂商 AI 协议、结构化输出、分析速度模式、单岗位重新分析、本地 JSON 容错、输入预算与会话存储边界。

## 发布验收

- 自动化测试：`tests/` 下 48 个测试脚本全部通过。
- 语法与格式：`background.js`、`content.js`、`popup.js`、`page-navigation-guard.js` 通过 Node 语法检查，JSON 文件解析成功，`git diff --check` 通过。
- 浏览器冒烟：Microsoft Edge 使用隔离临时配置成功加载扩展、后台 Service Worker 和配置页，配置页无 JavaScript 异常。
- 安全检查：未发现打包进仓库的 API Key、Bearer 凭据或私钥；原生点击仅接受 BOSS 职位页内容脚本发起，并限制为一次按下/释放序列。
- 发布包：ZIP 根目录直接包含 `manifest.json`，并包含运行所需脚本、样式、配置页、许可证和完整 PDF.js/CMap 资源。

SHA-256：`ff2bd370e0a272ed7ad0a33299c0d9b178eedf273efbfc85b749250d63d0e432`

真实账号下的“立即沟通”会产生实际外部操作，因此自动化验收不会擅自触发；发布后首次使用建议先选择少量明确测试岗位观察一轮。

## 安装与升级

1. 下载 `Job-Copilot-BOSS-Assistant-v1.0.0.zip` 并完整解压。
2. 在 Edge 或 Chrome 的扩展管理页开启开发者模式，选择“加载解压缩的扩展”。
3. 选择解压后直接包含 `manifest.json` 的目录。
4. 从旧版本升级时先暂停自动投递，重新加载扩展，并手动刷新已打开的 BOSS 职位列表页。

完整验收用例见 [`docs/releases/v1.0.0-test-matrix.md`](https://github.com/JackZeng1057/job-copilot-boss-assistant/blob/main/docs/releases/v1.0.0-test-matrix.md)。
